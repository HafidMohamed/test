🚫 Path Exclusion Test Page

This Page is Excluded from Translation

This page (/no-translate.html) is meant to be configured as a path exclusion in your dashboard. Once configured, this page will be served in the original language even when accessed via a translated subdomain (e.g., it.kaffeeröstreikreuzau.de/no-translate.html).

How to configure this:
Go to Dashboard → Languages → Excluded Paths and add:
/no-translate.html — excludes this exact page
/no-translate/ — excludes all pages under this path prefix
/admin/ — a common exclusion for admin panels
/api/ — exclude REST/JSON API responses
/cart, /checkout — exclude sensitive transaction pages

Why exclude a page?

  • Admin and back-office pages that staff use in a fixed language
  • API endpoints returning JSON — translation would corrupt the data
  • Cart and checkout flows where payment provider iframes are involved
  • Legal pages that are only valid in the original language
  • User-account pages where the content is user-generated and personal

What happens on excluded paths?

✅ Still works

  • The page loads normally on all subdomains
  • The language switcher widget is still injected
  • Hreflang tags still point to the correct subdomains
  • Media map image swaps still apply (optional)

🚫 Skipped

  • No text is sent to DeepL
  • All content appears in the original source language
  • No translation cost for this page
  • No cached translated version stored

Test it yourself

1. Add /no-translate.html to your excluded paths in the dashboard.
2. Visit it.kaffeeröstreikreuzau.de/no-translate.html — the content on this page will remain in English.
3. Then visit it.kaffeeröstreikreuzau.de/index.html — that page WILL be translated.
