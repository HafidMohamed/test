④ No-translate cases — MUST stay in source language ✗ KEEPS ORIGINAL

4a. <script> tag content ✗

JavaScript code inside <script> tags is never sent to the translation provider. This is intentional — translating JS would break the site.

View page source to confirm the id="demo-script" script block above contains untranslated JS.

4b. <style> tag content ✗

CSS inside <style> tags is never translated. View source to verify.

4c. <code> and <pre> tag content ✗

Inline code (stays in English):

Install the package with: npm install @kaffee/proxy-client --save

Set the environment variable: PROXY_API_KEY=pk_live_abc123def456

Code block (stays in English):

// Configure the proxy client
const proxy = new KaffeeProxy({
  apiKey: process.env.PROXY_API_KEY,
  targetLang: 'fr',
  originUrl: 'https://my-shop.de'

// Translate a page

⑧ Edge cases and complex patterns

Mixed inline content

This paragraph contains translatable text, then a no-translate code snippet (api_key=sk-test-abc123), then more translatable text about how to use it in your application.

Nested translate/no-translate

This outer paragraph is translatable and should appear in the target language. The price €12.90 must stay as-is. But this text after the price should also be translated.

Inside a translatable section, specific words like Kaffeerösterei can remain in their original form.

Numbers, emails, and dates in body text

Contact us at hello@kreuzau-kaffee.de or call +49 2422 12345 between Monday and Friday.

Our address is Rurstraße 12, 52372 Kreuzau, Germany. Orders over €40 qualify for free delivery.

Note: Emails and phone numbers in body text ARE sent to the translator (they are just text nodes). Use data-proxy-notranslate on the parent element to protect them.

Long content (batching test)

The proxy batches text nodes and sends them in groups to the translation provider. This paragraph is deliberately longer than the others to test that large text blocks are correctly handled, translated in full, and reassembled without losing context or breaking mid-sentence. The proxy must correctly associate each translated string with its original DOM node even when strings arrive out of order from the translation API. This tests the index-based write-back mechanism in the HTML rewriter pipeline.
