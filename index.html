Translation Exclusions — All Methods

Every method below prevents the marked content from being sent to the translation engine. Use whichever fits your CMS or workflow best.

❌ Not translated

1. HTML translate="no"

W3C standard. Works on any element. Child elements inherit it automatically.

This sentence MUST NOT be translated. Product-ID: XFACTOR-99. © 2024 BrandName Inc. All rights reserved.

<p translate="no">Never translate this</p>
❌ Not translated

2. data-proxy-notranslate

Proxy-native attribute. Protects the element and its entire subtree.

This is protected with data-proxy-notranslate and will never be sent to DeepL, regardless of its content.

<div data-proxy-notranslate="1">…</div>
❌ Not translated

3. data-wg-notranslate (Weglot compat)

If you migrated from Weglot, this attribute is honoured automatically — no migration needed.

Protected by data-wg-notranslate — same behaviour as data-proxy-notranslate.

<span data-wg-notranslate>…</span>
❌ Not translated (via Dashboard)

4. CSS Selector Exclusion

Go to Dashboard → Exclusions → Add CSS Selector and enter .no-translate. No code changes needed.

This paragraph has class="no-translate". Add that selector in the dashboard to protect it without touching your HTML.

Dashboard rule: .no-translate
🔒 Auto-excluded

5. <code> and <pre>

<script>, <style>, <code>, <pre>, <textarea>, <svg>, and <math> are all automatically excluded.

const price = 12.90; // not translated
function greet(name) {
  return `Hello, ${name}!`;
}
🔒 Auto-excluded

6. Inline SVG text

Inline SVG is never translated — text in charts, icons, and infographics stays exactly as authored.

Text inside SVG is never sent to the translation engine.

❌ Protect via CSS selector exclusion

Dynamic & Server-Generated Content

Prices, order IDs, stock counts, coupon codes, and barcodes are injected by your backend. They should never be translated.

Protect these in Dashboard → Exclusions: add selectors .price, .sku, .order-id, .stock-count, .barcode, .coupon-code, [data-price]. Everything inside those elements is left untouched.

🚫 Path exclusion — served in original language

Path / URL Exclusions

Admin panels, API endpoints, and pages that must remain in the original language can be excluded by path. The proxy serves them as-is for every language subdomain.

Dashboard → Languages → Excluded Paths: add /no-translate, /admin/, /api/, or any URL pattern.
Test it: no-translate.html — configure it as an excluded path, then visit it.kaffeeröstreikreuzau.de/no-translate.html — it will appear in English.
❌ Text exclusion — exact string kept verbatim

Brand Names & Text Exclusions

In Dashboard → Exclusions → Add Text Rule, enter an exact string that must never be translated. Even if DeepL suggests a localised version, the proxy preserves the original.

  • Brand name: Kaffeerösterei Kreuzau
  • Product line: Signature Blend №12
  • Certification: UTZ Certified
  • Legal entity: Kreuzau GmbH & Co. KG

You can also use Glossary Rules (Dashboard → Glossary) to force a specific translation — e.g., always translate "dark roast" as "torréfaction foncée" in French regardless of what DeepL suggests.
